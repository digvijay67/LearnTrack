# LearnTrack - Student & Course Management System

## Project Description
LearnTrack is a console-based **Student & Course Management System** developed in **Core Java**.  
It allows admins to manage:
- Students (add, list, deactivate)
- Courses (add, list, activate/deactivate)
- Enrollments (enroll students in courses, view enrollments)

The project focuses on **Core Java basics**, **OOP principles**, **ArrayList collections**, **menu-driven console UI**, and **basic exception handling**.

---

## How to Compile and Run

1. **JDK 17 or above** is installed and configured.
2. Open terminal in project root folder.
3. Compile Java files:

javac -d bin src/com/airtribe/learntrack/**/*.java
