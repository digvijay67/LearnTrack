
**What is JDK ,JRE ,JVM**
- JDK (Java development kit) : the jdk is a software package used by developers th create java program. it includes tools like the java compiler using command (javac). debugger and also contains the JRE.
- JRE (java runtime Enviornment): The JRE used th run the java program. it includes libraries and other import files in same package and another package need to execute java applications but does not include development tools.
- JVM (Java Virtual Machine): The JVM is the engine to that runs programs.it contains java bytecode int convert to machine code using machine specific instruction so the program can run on the depand on Computer.

**What is Bytecode ?**

- byte code is an intermediate form of code generated after compiling a java source file
-  it is not specific to any operating system . the JVM reads this bytecode and translates in into machine code at runtime.

** What does “write once, run anywhere” mean (1–2 short paragraphs)**

- write one run anywhere mesns that a java program only needs to be written and compiled once. the Same compiled program(bytecode) can run on any device that has a compatible JVM
- this is possible the jvm acts as a bridge between the program and the operating system. as long as the jum is available the java application can run without vhanges regarding nof the platform.
